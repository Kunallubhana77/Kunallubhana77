# How to Setup Your Advanced GitHub Profile

1.  **Create a New Repository**:
    *   Go to GitHub and create a new repository.
    *   **Important**: The repository name **must** be the same as your GitHub username (e.g., if your username is `kunallubhana`, the repo name must be `kunallubhana`).
    *   Initialize it with a README (optional, since we will replace it).

2.  **Upload Files**:
    *   Upload the `README.md` and `github_profile_header.png` from this folder to your new repository.

3.  **Edit the README**:
    *   Open the `README.md` file in GitHub (click the pencil icon).
    *   Replace `YOUR_USERNAME` with your actual GitHub username in all the URLs.
    *   Update the "About Me" section with your details.
    *   Update the social links at the bottom.

4.  **Commit Changes**:
    *   Commit the changes, and visit your profile page to see the new look!

## Customization Tips

*   **Themes**: You can change the `?theme=tokyonight` parameter in the stats URLs to other themes like `radical`, `merko`, `gruvbox`, etc.
*   **Icons**: You can find more badges at [Shields.io](https://shields.io/).
*   **Typing Effect**: You can customize the text in the typing SVG URL.
